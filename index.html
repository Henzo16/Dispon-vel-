Projetos em destaque

routConfig

Interface web para configuração de routers Cisco (séries 1800 e 1900) via ligação série, criada para eliminar a inserção manual de código no equipamento. O técnico preenche as variáveis num formulário e o sistema aplica as configurações de protocolos e serviços de rede automaticamente. Projeto avaliado em 19/20.

O que resolve

Reduz a fricção entre a linha de comandos do Cisco IOS e um fluxo de trabalho gerido por uma interface gráfica totalmente intuitiva, reduzindo o esforço mental e aumentando a rapidez na configuração de serviços e protocolos de rede.

Estado técnico

Estabilizado com 18 tabelas de base de dados antes de uma apresentação a investidores. Resolvido um bug de sincronização em que a função _merge_acls_with_db reativava registos de ACL que o utilizador tinha apagado. Sem bugs conhecidos em aberto.
